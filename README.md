# SE-Modmanager-Modlist
The modlist of the mod manager, I accept pr's here into the central system if they look good. 
This for now seemed like the best option over other solutions where I had to self host or insert google api nonsense but I'm open for discussion, just send me a ping in the Solar eclipse discord or here.

Here's an example on what should be appended where owner is Github user and repo the name of the repository (like both are in the url)
The teddit tag tells the mod manager how and where to treat is

    "Owner": "ted505",
    "Repo": "solar-expanse-teddit",
